# Wes Berry – Portfolio

Personal portfolio site built with vanilla HTML and CSS.

## Structure

- `index.html` – single-page layout with intro, about, and projects sections
- `styles.css` – all styles, including responsive breakpoints
- `images/` – photos and project screenshots
- `fonts/` – Roboto Mono variable font
- `Wesley_Berry_Resume.pdf` – resume

## Running locally

Open `index.html` directly in a browser — no build step required.
